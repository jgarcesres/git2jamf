# git2jamf v2 Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Rewrite git2jamf as v2: a composite GitHub Action (Python + uv) that syncs scripts and computer extension attribute scripts to Jamf Pro with ownership markers, safe deletes, dry run and sidecar settings, testable without a Jamf instance.

**Architecture:** Small modules with one job each under `src/git2jamf/`: `config` (inputs), `local` (filesystem scan), `metadata` (sidecars), `marker` (ownership block), `plan` (pure planning), `jamf` (HTTP client), `apply` (executes a plan), `report` (log, summary, outputs), `cli` (wiring). Nearly all logic lives in the pure `plan` module. Confidence without a Jamf instance comes from an in-memory fake Jamf server plus validation of every request and response against Jamf's published OpenAPI definitions.

**Tech Stack:** Python 3.11+ (3.13 in the action), uv, requests, PyYAML; pytest, pytest-cov, jsonschema, ruff for development.

**Spec:** `docs/superpowers/specs/2026-10-04-v2-design.md`. Read it before starting; this plan implements it.

**Provenance:** Every code block in this plan was written and run before the plan was committed: 156 tests pass with 99% branch coverage, ruff is clean, and the action job's flow (dry run, real run, no-op rerun, v1-input rejection) was simulated locally against the fake server. If a test fails while you follow the plan, the plan has a transcription error; compare with the block rather than changing the test.

### Deviations from the spec (intentional, decided while writing the plan)

1. **`marker.py` and `models.py` are separate modules.** The spec puts marker parsing in `plan.py`; splitting it out keeps `plan.py` focused and makes the marker format testable on its own.
2. **The action does not use `actions/setup-python`.** `setup-uv` plus `uv run --python 3.13` downloads a managed Python without changing the caller's PATH or default Python, so the action has no side effects on later steps in the user's job.
3. **End-to-end tests call `cli.main()` in-process** against the fake server, with one subprocess test for the console entry point. Faster, same coverage of the wiring.
4. **The "Try v2" issue is the existing tracking issue #26** (pinned), so the v1.4.1 notice can link to a URL that exists today.

## Review Focus

The inputs and conditions most likely to bite a real user that the spec implies but does not spell out. Each has a test in the task that owns the code:

1. **Jamf returns `null` for empty fields** (notes, info, parameters). Expected: treated as empty, so an unchanged script is not rewritten on every run. Test: `test_null_remote_fields_equal_empty_sidecar_values` (Task 6).
2. **An extension attribute with the same name exists in Jamf but is a pop-up, text or LDAP attribute.** Expected: refuse with a clear error, never convert it to a script. Test: `test_ea_with_non_script_input_type_is_refused` (Task 6).
3. **`script_dir` is the repository root**, which contains `.git/`, `.github/` and the `ea_dir`. Expected: dot-directories are skipped and extension attribute scripts are not also uploaded as scripts. Tests: `test_dot_directories_are_skipped`, `test_ea_dir_is_excluded_from_script_scan` (Task 5).
4. **Script files with a BOM, CRLF line endings or non-UTF-8 bytes.** Expected: uploaded byte-for-byte; CRLF-only differences do not count as changes; non-UTF-8 fails naming the file. Tests: `test_contents_are_byte_for_byte`, `test_non_utf8_file_is_an_error_naming_the_file` (Task 5), `test_unchanged_when_contents_equal_ignoring_crlf` (Task 6).
5. **"No category" has several spellings in Jamf** (`null`, `""`, `"-1"`). Expected: all equal a sidecar `category: null`. Test: `test_no_category_has_several_remote_spellings` (Task 6).

### Must be confirmed on a real Jamf Pro instance during the beta (Task 14)

The fake server follows the published schemas, but these behaviours are not documented precisely enough to be certain:

- `POST /api/v1/scripts` accepts `categoryId: "-1"` for "no category".
- `PUT /api/v1/scripts/{id}` with `categoryId` set and `categoryName` removed changes the category.
- `PUT /api/v1/computer-extension-attributes/{id}` accepts the full object returned by `GET` (including `id`).
- The list endpoint for extension attributes includes `description` (used to find owned objects without fetching each one).
- Which Jamf Pro version first supports `/api/v1/computer-extension-attributes` (for the README).

```python
"""Data types shared by every module."""

from __future__ import annotations

from dataclasses import dataclass, field
from enum import StrEnum
from pathlib import Path
from typing import Any


class Kind(StrEnum):
    SCRIPT = "script"
    EXTENSION_ATTRIBUTE = "extension_attribute"


class Verb(StrEnum):
    CREATE = "create"
    UPDATE = "update"
    ADOPT = "adopt"
    UNCHANGED = "unchanged"
    DELETE = "delete"
    ORPHANED = "orphaned"


# Jamf field holding the ownership marker and user text, per kind.
TEXT_FIELD = {Kind.SCRIPT: "notes", Kind.EXTENSION_ATTRIBUTE: "description"}


@dataclass(frozen=True)
class LocalObject:
    kind: Kind
    name: str
    path: Path
    contents: str
    # Validated sidecar values keyed by Jamf field name, plus the special keys
    # "category" (str | None) and "user_text" (str). Absent key = not managed.
    sidecar: dict[str, Any] = field(default_factory=dict)


@dataclass(frozen=True)
class RemoteObject:
    kind: Kind
    raw: dict[str, Any]

    @property
    def id(self) -> str:
        return str(self.raw["id"])

    @property
    def name(self) -> str:
        return self.raw["name"]

    @property
    def contents(self) -> str:
        return self.raw.get("scriptContents") or ""

    @property
    def text(self) -> str:
        return self.raw.get(TEXT_FIELD[self.kind]) or ""


@dataclass
class Action:
    kind: Kind
    verb: Verb
    name: str
    local: LocalObject | None = None
    remote: RemoteObject | None = None
    payload: dict[str, Any] | None = None
    changes: list[str] = field(default_factory=list)
```

```python
"""Sidecar (.yml) parsing and validation.

A sidecar maps friendly keys to Jamf API fields. The parsed result is a dict
keyed by Jamf field name, plus two special keys:
  "category"  -> category name, or None for "no category"
  "user_text" -> text kept below the git2jamf marker in notes/description
A key is present only if the sidecar sets it; absent keys are not managed.
"""

from __future__ import annotations

from pathlib import Path
from typing import Any

import yaml

from git2jamf.models import Kind

PRIORITIES = ("BEFORE", "AFTER", "AT_REBOOT")
DATA_TYPES = ("STRING", "INTEGER", "DATE")
INVENTORY_DISPLAYS = (
    "GENERAL",
    "HARDWARE",
    "OPERATING_SYSTEM",
    "USER_AND_LOCATION",
    "PURCHASING",
    "EXTENSION_ATTRIBUTES",
)

SCRIPT_KEYS = ("category", "priority", "info", "notes", "parameters", "os_requirements")
EA_KEYS = ("description", "data_type", "inventory_display", "enabled")


class SidecarError(Exception):
    pass


def load_sidecar(kind: Kind, path: Path) -> dict[str, Any]:
    try:
        data = yaml.safe_load(path.read_text(encoding="utf-8"))
    except (yaml.YAMLError, UnicodeDecodeError) as exc:
        raise SidecarError(f"{path}: not valid YAML: {exc}") from exc
    if data is None:
        return {}
    return parse_sidecar(kind, data, str(path))


def parse_sidecar(kind: Kind, data: Any, where: str) -> dict[str, Any]:
    if not isinstance(data, dict):
        raise SidecarError(f"{where}: expected a mapping of keys to values")
    allowed = SCRIPT_KEYS if kind is Kind.SCRIPT else EA_KEYS
    errors = [
        f"{where}: unknown key '{key}' (allowed: {', '.join(allowed)})"
        for key in data
        if key not in allowed
    ]
    out: dict[str, Any] = {}
    for key, value in data.items():
        if key not in allowed:
            continue
        try:
            out.update(_convert(key, value))
        except SidecarError as exc:
            errors.append(f"{where}: {exc}")
    if errors:
        raise SidecarError("\n".join(errors))
    return out


def _convert(key: str, value: Any) -> dict[str, Any]:
    if key == "category":
        if value is not None and not isinstance(value, str):
            raise SidecarError("'category' must be a category name or null")
        return {"category": value}
    if key == "priority":
        return {"priority": _enum(key, value, PRIORITIES)}
    if key == "info":
        return {"info": _string(key, value)}
    if key in ("notes", "description"):
        return {"user_text": _string(key, value)}
    if key == "os_requirements":
        return {"osRequirements": _string(key, value)}
    if key == "parameters":
        return _parameters(value)
    if key == "data_type":
        return {"dataType": _enum(key, value, DATA_TYPES)}
    if key == "inventory_display":
        return {"inventoryDisplayType": _enum(key, value, INVENTORY_DISPLAYS)}
    if key == "enabled":
        if not isinstance(value, bool):
            raise SidecarError("'enabled' must be true or false")
        return {"enabled": value}
    raise AssertionError(key)  # pragma: no cover - guarded by allowed keys


def _string(key: str, value: Any) -> str:
    if not isinstance(value, str):
        raise SidecarError(f"'{key}' must be a string")
    return value


def _enum(key: str, value: Any, choices: tuple[str, ...]) -> str:
    if not isinstance(value, str) or value.upper() not in choices:
        raise SidecarError(f"'{key}' must be one of {', '.join(choices)}")
    return value.upper()


def _parameters(value: Any) -> dict[str, str]:
    if not isinstance(value, dict):
        raise SidecarError("'parameters' must map parameter numbers (4-11) to labels")
    out = {}
    for number, label in value.items():
        if not isinstance(number, int) or isinstance(number, bool) or not 4 <= number <= 11:
            raise SidecarError(f"parameter number {number!r} must be an integer from 4 to 11")
        out[f"parameter{number}"] = _string(f"parameters.{number}", label)
    return out
```

```python
"""The git2jamf ownership marker kept at the top of notes/description.

    git2jamf: owner=<owner> prefix=<prefix>
    git2jamf: created <YYYY-MM-DD>
    git2jamf: updated <YYYY-MM-DD> (commit <sha>)
    <user text>

Every consecutive leading line starting with "git2jamf:" is part of the block.
"""

from __future__ import annotations

import re
from dataclasses import dataclass

LINE_PREFIX = "git2jamf:"
_OWNER = re.compile(r"^git2jamf: owner=(?P<owner>\S+) prefix=(?P<prefix>\S*)$")
_CREATED = re.compile(r"^git2jamf: created (?P<value>.+)$")
_UPDATED = re.compile(r"^git2jamf: updated (?P<value>.+)$")


@dataclass(frozen=True)
class Marker:
    owner: str | None = None
    prefix: str | None = None
    created: str | None = None
    updated: str | None = None

    @property
    def owned(self) -> bool:
        return self.owner is not None

    def belongs_to(self, owner: str, prefix: str) -> bool:
        return self.owner == owner and self.prefix == prefix


def parse(text: str | None) -> tuple[Marker, str]:
    """Split text into (marker, user text)."""
    lines = (text or "").replace("\r\n", "\n").split("\n")
    owner = prefix = created = updated = None
    count = 0
    for line in lines:
        if not line.startswith(LINE_PREFIX):
            break
        count += 1
        if m := _OWNER.match(line):
            owner, prefix = m["owner"], m["prefix"]
        elif m := _CREATED.match(line):
            created = m["value"]
        elif m := _UPDATED.match(line):
            updated = m["value"]
    user_text = "\n".join(lines[count:])
    return Marker(owner, prefix, created, updated), user_text


def render(marker: Marker, user_text: str) -> str:
    lines = [f"{LINE_PREFIX} owner={marker.owner} prefix={marker.prefix or ''}"]
    if marker.created:
        lines.append(f"{LINE_PREFIX} created {marker.created}")
    if marker.updated:
        lines.append(f"{LINE_PREFIX} updated {marker.updated}")
    if user_text:
        lines.append(user_text)
    return "\n".join(lines)
```

```python
"""Inputs -> validated Settings.

Every option is a CLI flag whose default comes from the matching INPUT_* env
var, which is how the composite action passes its inputs. Validation collects
every problem and reports them together.
"""

from __future__ import annotations

import argparse
import os
from collections.abc import Mapping, Sequence
from dataclasses import dataclass
from pathlib import Path
from urllib.parse import urlparse

MIGRATION_URL = "https://github.com/jgarcesres/git2jamf#migrating-from-v1"

# (flag, env var, help)
OPTIONS = [
    ("jamf-url", "INPUT_JAMF_URL", "Jamf Pro URL, e.g. https://acme.jamfcloud.com"),
    ("jamf-client-id", "INPUT_JAMF_CLIENT_ID", "API client ID"),
    ("jamf-client-secret", "INPUT_JAMF_CLIENT_SECRET", "API client secret"),
    ("jamf-username", "INPUT_JAMF_USERNAME", "Jamf Pro username"),
    ("jamf-password", "INPUT_JAMF_PASSWORD", "Jamf Pro password"),
    ("script-dir", "INPUT_SCRIPT_DIR", "Directory of scripts"),
    ("ea-dir", "INPUT_EA_DIR", "Directory of extension attribute scripts"),
    ("script-extensions", "INPUT_SCRIPT_EXTENSIONS", "Space-separated extensions"),
    ("prefix", "INPUT_PREFIX", "Prefix added to every name as <prefix>_<name>"),
    ("delete", "INPUT_DELETE", "Delete owned objects missing locally (true/false)"),
    ("dry-run", "INPUT_DRY_RUN", "Plan only, change nothing (true/false)"),
    ("owner", "INPUT_OWNER", "Ownership scope recorded in the marker"),
]
DEPRECATED = {
    "INPUT_JAMF_AUTH_TYPE": "jamf_auth_type was removed in v2: set jamf_client_id and "
    "jamf_client_secret for API clients, or jamf_username and jamf_password.",
    "INPUT_EA_SCRIPT_DIR": "ea_script_dir was renamed to ea_dir in v2.",
}
DEFAULT_EXTENSIONS = "sh zsh py"


class ConfigError(Exception):
    def __init__(self, problems: list[str]):
        super().__init__("\n".join(problems))
        self.problems = problems


@dataclass(frozen=True)
class Settings:
    jamf_url: str
    client_id: str | None
    client_secret: str | None
    username: str | None
    password: str | None
    script_dir: Path | None
    ea_dir: Path | None
    script_extensions: tuple[str, ...]
    prefix: str
    delete: bool
    dry_run: bool
    owner: str
    commit: str | None
    summary_path: Path | None
    output_path: Path | None


def load(argv: Sequence[str] | None = None, env: Mapping[str, str] | None = None) -> Settings:
    env = os.environ if env is None else env
    parser = argparse.ArgumentParser(prog="git2jamf", description="Sync scripts to Jamf Pro.")
    for flag, var, help_text in OPTIONS:
        parser.add_argument(f"--{flag}", default=env.get(var, ""), help=help_text)
    args = vars(parser.parse_args(argv if argv is not None else []))
    raw = {key: (value or "").strip() for key, value in args.items()}
    return _build(raw, env)


def _build(raw: dict[str, str], env: Mapping[str, str]) -> Settings:
    problems: list[str] = []
    for var, message in DEPRECATED.items():
        if env.get(var, "").strip():
            problems.append(f"{message} See {MIGRATION_URL}")

    url = raw["jamf_url"].rstrip("/")
    parsed = urlparse(url)
    if not url:
        problems.append("jamf_url is required.")
    elif parsed.scheme == "http" and parsed.hostname in ("localhost", "127.0.0.1"):
        pass
    elif parsed.scheme != "https" or not parsed.hostname:
        problems.append(f"jamf_url must be an https:// URL, got {url!r}.")

    client = (raw["jamf_client_id"], raw["jamf_client_secret"])
    user = (raw["jamf_username"], raw["jamf_password"])
    has_client, has_user = any(client), any(user)
    if has_client and has_user:
        problems.append(
            "Set either jamf_client_id/jamf_client_secret or jamf_username/jamf_password, not both."
        )
    elif has_client and not all(client):
        problems.append("jamf_client_id and jamf_client_secret must both be set.")
    elif has_user and not all(user):
        problems.append("jamf_username and jamf_password must both be set.")
    elif not has_client and not has_user:
        problems.append(
            "Credentials are required: jamf_client_id and jamf_client_secret "
            "(recommended), or jamf_username and jamf_password."
        )

    base = Path(env.get("GITHUB_WORKSPACE") or os.getcwd())
    script_dir = _directory("script_dir", raw["script_dir"], base, problems)
    ea_dir = _directory("ea_dir", raw["ea_dir"], base, problems)
    if not raw["script_dir"] and not raw["ea_dir"]:
        problems.append("Set script_dir, ea_dir, or both.")
    if script_dir and ea_dir and script_dir == ea_dir:
        problems.append("script_dir and ea_dir must be different directories.")

    extensions = tuple(
        ext.lstrip(".") for ext in (raw["script_extensions"] or DEFAULT_EXTENSIONS).split()
    )

    prefix = raw["prefix"]
    if prefix.lower() in ("true", "false"):
        problems.append(
            f"prefix is now a string, not true/false (got {prefix!r}). See {MIGRATION_URL}"
        )
    elif any(c.isspace() for c in prefix):
        problems.append(f"prefix must not contain whitespace, got {prefix!r}.")

    delete = _boolean("delete", raw["delete"], problems)
    dry_run = _boolean("dry_run", raw["dry_run"], problems)

    owner = raw["owner"]
    if not owner:
        problems.append("owner is required (in GitHub Actions it defaults to the repository).")
    elif any(c.isspace() for c in owner):
        problems.append(f"owner must not contain whitespace, got {owner!r}.")

    if problems:
        raise ConfigError(problems)

    sha = env.get("GITHUB_SHA", "").strip()
    return Settings(
        jamf_url=url,
        client_id=client[0] or None,
        client_secret=client[1] or None,
        username=user[0] or None,
        password=user[1] or None,
        script_dir=script_dir,
        ea_dir=ea_dir,
        script_extensions=extensions,
        prefix=prefix,
        delete=delete,
        dry_run=dry_run,
        owner=owner,
        commit=sha[:7] or None,
        summary_path=_optional_path(env.get("GITHUB_STEP_SUMMARY")),
        output_path=_optional_path(env.get("GITHUB_OUTPUT")),
    )


def _directory(name: str, value: str, base: Path, problems: list[str]) -> Path | None:
    if not value:
        return None
    path = Path(value)
    path = (path if path.is_absolute() else base / path).resolve()
    if not path.is_dir():
        problems.append(f"{name} {value!r} is not a directory (resolved to {path}).")
        return None
    return path


def _boolean(name: str, value: str, problems: list[str]) -> bool:
    lowered = value.lower()
    if lowered in ("", "false"):
        return False
    if lowered == "true":
        return True
    problems.append(f"{name} must be true or false, got {value!r}.")
    return False


def _optional_path(value: str | None) -> Path | None:
    return Path(value) if value else None
```

```python
"""Scan the repository for scripts, extension attribute scripts and sidecars."""

from __future__ import annotations

from dataclasses import dataclass, field
from pathlib import Path

from git2jamf.metadata import SidecarError, load_sidecar
from git2jamf.models import Kind, LocalObject


class ScanError(Exception):
    def __init__(self, problems: list[str]):
        super().__init__("\n".join(problems))
        self.problems = problems


@dataclass
class ScanResult:
    objects: list[LocalObject] = field(default_factory=list)
    warnings: list[str] = field(default_factory=list)


def scan(
    script_dir: Path | None,
    ea_dir: Path | None,
    extensions: tuple[str, ...],
    prefix: str,
) -> ScanResult:
    result = ScanResult()
    problems: list[str] = []
    exclude = [ea_dir] if ea_dir else []
    if script_dir:
        _scan_dir(Kind.SCRIPT, script_dir, exclude, extensions, prefix, result, problems)
    if ea_dir:
        _scan_dir(Kind.EXTENSION_ATTRIBUTE, ea_dir, [], extensions, prefix, result, problems)
    if problems:
        raise ScanError(problems)
    return result


def _scan_dir(
    kind: Kind,
    root: Path,
    exclude: list[Path],
    extensions: tuple[str, ...],
    prefix: str,
    result: ScanResult,
    problems: list[str],
) -> None:
    suffixes = {f".{ext.lower()}" for ext in extensions}
    used_sidecars: set[Path] = set()
    sidecars: list[Path] = []
    for path in sorted(root.rglob("*")):
        if not path.is_file() or _skipped(path, root, exclude):
            continue
        if path.suffix == ".yml":
            sidecars.append(path)
            continue
        if path.suffix.lower() not in suffixes:
            continue
        try:
            contents = path.read_bytes().decode("utf-8")
        except UnicodeDecodeError:
            problems.append(f"{path}: not valid UTF-8")
            continue
        sidecar_path = path.with_suffix(".yml")
        sidecar = {}
        if sidecar_path.is_file():
            used_sidecars.add(sidecar_path)
            try:
                sidecar = load_sidecar(kind, sidecar_path)
            except SidecarError as exc:
                problems.append(str(exc))
        name = f"{prefix}_{path.stem}" if prefix else path.stem
        result.objects.append(LocalObject(kind, name, path, contents, sidecar))
    for sidecar_path in sidecars:
        if sidecar_path not in used_sidecars:
            result.warnings.append(f"{sidecar_path}: no matching script, ignored")


def _skipped(path: Path, root: Path, exclude: list[Path]) -> bool:
    relative = path.relative_to(root)
    if any(part.startswith(".") for part in relative.parts):
        return True
    return any(path.is_relative_to(other) for other in exclude)
```

```python
"""Pure planning: local objects + remote objects -> list of actions. No I/O."""

from __future__ import annotations

from collections import defaultdict
from dataclasses import dataclass
from typing import Any

from git2jamf import marker
from git2jamf.models import TEXT_FIELD, Action, Kind, LocalObject, RemoteObject, Verb

NO_CATEGORY = "-1"
SCRIPT_DEFAULTS: dict[str, Any] = {"priority": "AFTER", "categoryId": NO_CATEGORY}
EA_DEFAULTS: dict[str, Any] = {
    "inputType": "SCRIPT",
    "dataType": "STRING",
    "inventoryDisplayType": "EXTENSION_ATTRIBUTES",
    "enabled": True,
}
_SPECIAL_KEYS = ("category", "user_text")


class PlanError(Exception):
    def __init__(self, problems: list[str]):
        super().__init__("\n".join(problems))
        self.problems = problems


@dataclass(frozen=True)
class PlanSettings:
    owner: str
    prefix: str
    delete: bool
    kinds: frozenset[Kind]
    today: str
    commit: str | None


def build_plan(
    local: list[LocalObject],
    remote: list[RemoteObject],
    settings: PlanSettings,
    categories: dict[str, tuple[str, str]] | None = None,
) -> list[Action]:
    """categories maps lower-case category name -> (id, name)."""
    categories = categories or {}
    problems: list[str] = []
    actions: list[Action] = []

    local_by_key: dict[tuple[Kind, str], list[LocalObject]] = defaultdict(list)
    for obj in local:
        local_by_key[(obj.kind, obj.name.lower())].append(obj)
    remote_by_key: dict[tuple[Kind, str], list[RemoteObject]] = defaultdict(list)
    for obj in remote:
        remote_by_key[(obj.kind, obj.name.lower())].append(obj)

    for (kind, _), objs in local_by_key.items():
        if len(objs) > 1:
            paths = ", ".join(str(o.path) for o in objs)
            problems.append(
                f"{kind}: {len(objs)} local files map to the name '{objs[0].name}': {paths}"
            )

    if settings.delete:
        for kind in sorted(settings.kinds):
            if not any(o.kind is kind for o in local):
                problems.append(
                    f"delete is enabled but no local {kind} files were found; "
                    "refusing to delete everything. Check the directory setting."
                )

    for (kind, key), objs in local_by_key.items():
        obj = objs[0]
        matches = remote_by_key.get((kind, key), [])
        if len(matches) > 1:
            names = ", ".join(f"'{m.name}' (id {m.id})" for m in matches)
            problems.append(f"{kind} '{obj.name}' matches {len(matches)} objects in Jamf: {names}")
            continue
        try:
            actions.append(_plan_local(obj, matches[0] if matches else None, settings, categories))
        except PlanError as exc:
            problems.extend(exc.problems)

    for (kind, key), objs in remote_by_key.items():
        if (kind, key) in local_by_key or kind not in settings.kinds:
            continue
        for obj in objs:
            owned, _ = marker.parse(obj.text)
            if owned.belongs_to(settings.owner, settings.prefix):
                verb = Verb.DELETE if settings.delete else Verb.ORPHANED
                actions.append(Action(kind, verb, obj.name, remote=obj))

    if problems:
        raise PlanError(problems)
    return sorted(actions, key=lambda a: (list(Verb).index(a.verb), a.kind, a.name.lower()))


def _plan_local(
    obj: LocalObject,
    remote: RemoteObject | None,
    settings: PlanSettings,
    categories: dict[str, tuple[str, str]],
) -> Action:
    desired = _desired_fields(obj, categories)
    text_field = TEXT_FIELD[obj.kind]
    stamp = settings.today + (f" (commit {settings.commit})" if settings.commit else "")

    if remote is None:
        defaults = SCRIPT_DEFAULTS if obj.kind is Kind.SCRIPT else EA_DEFAULTS
        new_marker = marker.Marker(settings.owner, settings.prefix, settings.today)
        payload = {
            **defaults,
            **desired,
            "name": obj.name,
            "scriptContents": obj.contents,
            text_field: marker.render(new_marker, obj.sidecar.get("user_text", "")),
        }
        return Action(obj.kind, Verb.CREATE, obj.name, local=obj, payload=payload)

    if obj.kind is Kind.EXTENSION_ATTRIBUTE and remote.raw.get("inputType") not in (
        None,
        "SCRIPT",
    ):
        raise PlanError(
            [
                f"extension_attribute '{obj.name}' exists in Jamf with input type "
                f"{remote.raw['inputType']}; refusing to replace it with a script."
            ]
        )

    current, user_text = marker.parse(remote.text)
    if current.owned and not current.belongs_to(settings.owner, settings.prefix):
        raise PlanError(
            [
                f"{obj.kind} '{obj.name}' is managed by owner={current.owner} "
                f"prefix={current.prefix or ''}, not by this run "
                f"(owner={settings.owner} prefix={settings.prefix})."
            ]
        )

    changes = _changes(obj, remote, desired, user_text)
    new_user_text = obj.sidecar.get("user_text", user_text)
    verb = Verb.ADOPT if not current.owned else (Verb.UPDATE if changes else Verb.UNCHANGED)
    if verb is Verb.UNCHANGED:
        return Action(obj.kind, verb, obj.name, local=obj, remote=remote)

    new_marker = marker.Marker(
        settings.owner,
        settings.prefix,
        current.created or settings.today,
        stamp if changes else current.updated,
    )
    payload = {
        **remote.raw,
        **desired,
        "scriptContents": obj.contents,
        text_field: marker.render(new_marker, new_user_text),
    }
    if "categoryId" in desired:
        payload.pop("categoryName", None)
    return Action(
        obj.kind, verb, obj.name, local=obj, remote=remote, payload=payload, changes=changes
    )


def _desired_fields(obj: LocalObject, categories: dict[str, tuple[str, str]]) -> dict[str, Any]:
    desired = {k: v for k, v in obj.sidecar.items() if k not in _SPECIAL_KEYS}
    if "category" in obj.sidecar:
        name = obj.sidecar["category"]
        if name is None:
            desired["categoryId"] = NO_CATEGORY
        elif name.lower() in categories:
            desired["categoryId"] = categories[name.lower()][0]
        else:
            raise PlanError([f"{obj.path}: category '{name}' does not exist in Jamf."])
    return desired


def _changes(
    obj: LocalObject, remote: RemoteObject, desired: dict[str, Any], user_text: str
) -> list[str]:
    changes = []
    if _normalize(obj.contents) != _normalize(remote.contents):
        changes.append("contents")
    for key, value in desired.items():
        current = remote.raw.get(key)
        if key == "categoryId":
            if _category(current) != _category(value):
                changes.append("category")
        elif _empty_as_blank(current) != _empty_as_blank(value):
            changes.append(key)
    if "user_text" in obj.sidecar and obj.sidecar["user_text"].rstrip() != user_text.rstrip():
        changes.append(TEXT_FIELD[obj.kind])
    return changes


def _normalize(text: str) -> str:
    return text.replace("\r\n", "\n")


def _empty_as_blank(value: Any) -> Any:
    return "" if value is None else value


def _category(value: Any) -> str:
    return NO_CATEGORY if value in (None, "", NO_CATEGORY) else str(value)
```

````python
dropped because its version changes with every Jamf release.

Usage: uv run python scripts/fetch_openapi.py
"""

from __future__ import annotations

import json
import re
import sys
from pathlib import Path

import requests

BASE = "https://developer.jamf.com/jamf-pro/reference/{slug}.md"
OUT = Path(__file__).resolve().parent.parent / "tests" / "openapi"
SLUGS = [
    "postoauthtoken",
    "post_v1-auth-token",
    "post_v1-auth-invalidate-token",
    "get_v1-scripts",
    "post_v1-scripts",
    "put_v1-scripts-id",
    "delete_v1-scripts-id",
    "get_v1-categories",
    "get_v1-computer-extension-attributes",
    "post_v1-computer-extension-attributes",
    "get_v1-computer-extension-attributes-id",
    "put_v1-computer-extension-attributes-id",
    "delete_v1-computer-extension-attributes-id",
    "get_v1-computer-extension-attributes-id-data-dependency",
]
_BLOCK = re.compile(r"# OpenAPI definition\s*```json\n(.*?)\n```", re.S)


def fetch(slug: str) -> dict:
    response = requests.get(BASE.format(slug=slug), timeout=30)
    response.raise_for_status()
    match = _BLOCK.search(response.text)
    if not match:
        raise SystemExit(f"{slug}: no OpenAPI definition found on the page")
    doc = json.loads(match.group(1))
    doc.pop("info", None)
    return doc


def main() -> int:
    OUT.mkdir(parents=True, exist_ok=True)
    for slug in SLUGS:
        doc = fetch(slug)
        (OUT / f"{slug}.json").write_text(json.dumps(doc, indent=2, sort_keys=True) + "\n")
        print(f"wrote {slug}.json")
    return 0


if __name__ == "__main__":
    sys.exit(main())
````

```python
"""In-memory fake of the Jamf Pro API endpoints git2jamf uses.

Only what git2jamf calls is implemented, with Jamf's paging, bearer tokens and
status codes as documented in tests/openapi/. Every request and response is
recorded so contract tests can validate them against the OpenAPI definitions.
"""

from __future__ import annotations

import base64
import itertools
import json
import re
import threading
import time
from dataclasses import dataclass, field
from datetime import UTC, datetime, timedelta
from http.server import BaseHTTPRequestHandler, ThreadingHTTPServer
from typing import Any
from urllib.parse import parse_qs, urlparse

CLIENT_ID, CLIENT_SECRET = "client-id", "client-secret"
USERNAME, PASSWORD = "admin", "password"


@dataclass
class Fault:
    method: str
    path: str  # regex matched against the path, e.g. r"/api/v1/scripts$"
    status: int
    times: int = 1
    headers: dict[str, str] = field(default_factory=dict)
    delay: float = 0.0


@dataclass
class Exchange:
    method: str
    path: str
    query: dict[str, list[str]]
    headers: dict[str, str]
    body: Any
    status: int
    response: Any


class FakeJamf:
    def __init__(self) -> None:
        self.scripts: dict[str, dict] = {}
        self.eas: dict[str, dict] = {}
        self.categories: dict[str, dict] = {}
        self.dependencies: dict[str, list[dict]] = {}
        self.exchanges: list[Exchange] = []
        self.faults: list[Fault] = []
        self.tokens: dict[str, float] = {}
        self.token_ttl = 1200
        self.oauth_v1_enabled = True
        self.ea_enabled = True
        self._ids = itertools.count(1)
        self._lock = threading.Lock()
        self._server: ThreadingHTTPServer | None = None

    # -- seeding -----------------------------------------------------------
    def add_script(self, name: str, contents: str = "", **fields: Any) -> str:
        sid = str(next(self._ids))
        self.scripts[sid] = {
            "id": sid,
            "name": name,
            "info": "",
            "notes": "",
            "priority": "AFTER",
            "categoryId": "-1",
            "categoryName": "NONE",
            "parameter4": "",
            "parameter5": "",
            "parameter6": "",
            "parameter7": "",
            "parameter8": "",
            "parameter9": "",
            "parameter10": "",
            "parameter11": "",
            "osRequirements": "",
            "scriptContents": contents,
            **fields,
        }
        return sid

    def add_ea(self, name: str, contents: str = "", **fields: Any) -> str:
        eid = str(next(self._ids))
        self.eas[eid] = {
            "id": eid,
            "name": name,
            "description": "",
            "dataType": "STRING",
            "enabled": True,
            "inventoryDisplayType": "EXTENSION_ATTRIBUTES",
            "inputType": "SCRIPT",
            "scriptContents": contents,
            **fields,
        }
        return eid

    def add_category(self, name: str) -> str:
        cid = str(next(self._ids))
        self.categories[cid] = {"id": cid, "name": name, "priority": 9}
        return cid

    def fail(self, method: str, path: str, status: int, **kwargs: Any) -> None:
        self.faults.append(Fault(method, path, status, **kwargs))

    def expire_tokens(self) -> None:
        self.tokens = {token: 0.0 for token in self.tokens}

    def requests_to(self, method: str, path: str) -> list[Exchange]:
        return [e for e in self.exchanges if e.method == method and re.search(path, e.path)]

    def state(self) -> dict[str, Any]:
        return {"scripts": list(self.scripts.values()), "eas": list(self.eas.values())}

    # -- server lifecycle --------------------------------------------------
    def start(self, port: int = 0) -> str:
        fake = self

        class Handler(_Handler):
            jamf = fake

        self._server = ThreadingHTTPServer(("127.0.0.1", port), Handler)
        threading.Thread(
            target=self._server.serve_forever, kwargs={"poll_interval": 0.01}, daemon=True
        ).start()
        return f"http://127.0.0.1:{self._server.server_address[1]}"

    def stop(self) -> None:
        if self._server:
            self._server.shutdown()
            self._server.server_close()
            self._server = None

    # -- request handling --------------------------------------------------
    def handle(self, method: str, path: str, query: dict, headers: dict, body: Any):
        with self._lock:
            for fault in self.faults:
                if fault.method == method and re.search(fault.path, path) and fault.times > 0:
                    fault.times -= 1
                    if fault.delay:
                        time.sleep(fault.delay)
                    return fault.status, {"httpStatus": fault.status, "errors": []}, fault.headers
            return self._route(method, path, query, headers, body)

    def _route(self, method, path, query, headers, body):
        if method == "POST" and path in ("/api/v1/oauth/token", "/api/oauth/token"):
            if path == "/api/v1/oauth/token" and not self.oauth_v1_enabled:
                return 404, {"httpStatus": 404, "errors": []}, {}
            if (
                (body or {}).get("client_id") != CLIENT_ID
                or body.get("client_secret") != CLIENT_SECRET
                or body.get("grant_type") != "client_credentials"
            ):
                return 401, {"error": "invalid_client"}, {}
            token = self._issue()
            return (
                200,
                {
                    "access_token": token,
                    "token_type": "Bearer",
                    "scope": "api-role:1",
                    "expires_in": self.token_ttl,
                },
                {},
            )
        if method == "POST" and path == "/api/v1/auth/token":
            expected = "Basic " + base64.b64encode(f"{USERNAME}:{PASSWORD}".encode()).decode()
            if headers.get("authorization") != expected:
                return 401, {"httpStatus": 401, "errors": []}, {}
            token = self._issue()
            expires = datetime.now(UTC) + timedelta(seconds=self.token_ttl)
            return 200, {"token": token, "expires": expires.isoformat().replace("+00:00", "Z")}, {}

        token = (headers.get("authorization") or "").removeprefix("Bearer ")
        if self.tokens.get(token, 0) < time.monotonic():
            return 401, {"httpStatus": 401, "errors": []}, {}

        if method == "POST" and path == "/api/v1/auth/invalidate-token":
            self.tokens.pop(token, None)
            return 204, None, {}
        if path == "/api/v1/categories" and method == "GET":
            return 200, _page(self.categories, query), {}
        if path.startswith("/api/v1/scripts"):
            return _crud(
                self.scripts, "/api/v1/scripts", method, path, query, body, 200, self._next_id
            )
        if path.startswith("/api/v1/computer-extension-attributes"):
            if not self.ea_enabled:
                return 404, {"httpStatus": 404, "errors": []}, {}
            m = re.fullmatch(r"/api/v1/computer-extension-attributes/(\w+)/data-dependency", path)
            if m and method == "GET":
                if m[1] not in self.eas:
                    return 404, {"httpStatus": 404, "errors": []}, {}
                deps = self.dependencies.get(m[1], [])
                return 200, {"totalCount": len(deps), "results": deps}, {}
            if method == "GET" and path == "/api/v1/computer-extension-attributes":
                status, page, hdrs = 200, _page(self.eas, query), {}
                page["results"] = [
                    {k: v for k, v in r.items() if k != "scriptContents"} for r in page["results"]
                ]
                return status, page, hdrs
            return _crud(
                self.eas,
                "/api/v1/computer-extension-attributes",
                method,
                path,
                query,
                body,
                202,
                self._next_id,
            )
        return 404, {"httpStatus": 404, "errors": []}, {}

    def _issue(self) -> str:
        token = f"token-{next(self._ids)}"
        self.tokens[token] = time.monotonic() + self.token_ttl
        return token

    def _next_id(self) -> str:
        return str(next(self._ids))


def _page(store: dict[str, dict], query: dict) -> dict:
    page = int(query.get("page", ["0"])[0])
    size = int(query.get("page-size", ["100"])[0])
    items = sorted(store.values(), key=lambda r: int(r["id"]))
    return {"totalCount": len(items), "results": items[page * size : (page + 1) * size]}


def _crud(store, base, method, path, query, body, put_status, next_id):
    if path == base:
        if method == "GET":
            return 200, _page(store, query), {}
        if method == "POST":
            new_id = next_id()
            store[new_id] = {**body, "id": new_id}
            return 201, {"id": new_id, "href": f"{base}/{new_id}"}, {}
    m = re.fullmatch(re.escape(base) + r"/(\w+)", path)
    if m:
        item_id = m[1]
        if item_id not in store:
            return 404, {"httpStatus": 404, "errors": []}, {}
        if method == "GET":
            return 200, store[item_id], {}
        if method == "PUT":
            store[item_id] = {**store[item_id], **body, "id": item_id}
            return put_status, store[item_id], {}
        if method == "DELETE":
            del store[item_id]
            return 204, None, {}
    return 405, {"httpStatus": 405, "errors": []}, {}


class _Handler(BaseHTTPRequestHandler):
    jamf: FakeJamf

    def log_message(self, *args: Any) -> None:  # keep test output quiet
        pass

    def _dispatch(self, method: str) -> None:
        url = urlparse(self.path)
        length = int(self.headers.get("content-length") or 0)
        raw = self.rfile.read(length).decode() if length else ""
        content_type = self.headers.get("content-type") or ""
        if "x-www-form-urlencoded" in content_type:
            body: Any = {k: v[0] for k, v in parse_qs(raw).items()}
        else:
            body = json.loads(raw) if raw else None
        headers = {k.lower(): v for k, v in self.headers.items()}
        if url.path == "/__state" and method == "GET":
            status, response, extra = 200, self.jamf.state(), {}
        else:
            query = parse_qs(url.query)
            status, response, extra = self.jamf.handle(method, url.path, query, headers, body)
            self.jamf.exchanges.append(
                Exchange(method, url.path, query, headers, body, status, response)
            )
        payload = b"" if response is None else json.dumps(response).encode()
        self.send_response(status)
        for key, value in extra.items():
            self.send_header(key, value)
        if payload:
            self.send_header("content-type", "application/json")
        self.send_header("content-length", str(len(payload)))
        self.end_headers()
        self.wfile.write(payload)

    def do_GET(self) -> None:  # noqa: N802
        self._dispatch("GET")

    def do_POST(self) -> None:  # noqa: N802
        self._dispatch("POST")

    def do_PUT(self) -> None:  # noqa: N802
        self._dispatch("PUT")

    def do_DELETE(self) -> None:  # noqa: N802
        self._dispatch("DELETE")
```

```python
ROUTES = [
    ("POST", r"^/api/v1/oauth/token$", "postoauthtoken"),
    ("POST", r"^/api/v1/auth/token$", "post_v1-auth-token"),
    ("POST", r"^/api/v1/auth/invalidate-token$", "post_v1-auth-invalidate-token"),

    ("PUT", r"^/api/v1/scripts/\w+$", "put_v1-scripts-id"),
    ("DELETE", r"^/api/v1/scripts/\w+$", "delete_v1-scripts-id"),
    ("GET", r"^/api/v1/categories$", "get_v1-categories"),
    ("GET", r"^/api/v1/computer-extension-attributes$", "get_v1-computer-extension-attributes"),
    ("POST", r"^/api/v1/computer-extension-attributes$", "post_v1-computer-extension-attributes"),
    (
        "GET",
        r"^/api/v1/computer-extension-attributes/\w+$",
        "get_v1-computer-extension-attributes-id",
    ),
    (
        "PUT",
        r"^/api/v1/computer-extension-attributes/\w+$",
        "put_v1-computer-extension-attributes-id",
    ),
    (
        "DELETE",
        r"^/api/v1/computer-extension-attributes/\w+$",
        "delete_v1-computer-extension-attributes-id",
    ),
    (
        "GET",
        r"^/api/v1/computer-extension-attributes/\w+/data-dependency$",
        "get_v1-computer-extension-attributes-id-data-dependency",
    ),
]


def slug_for(method: str, path: str) -> str | None:
    for route_method, pattern, slug in ROUTES:
        if route_method == method and re.match(pattern, path):
            return slug
    return None


@cache
def _doc(slug: str) -> dict:
    return json.loads((OPENAPI_DIR / f"{slug}.json").read_text())


def _operation(slug: str) -> dict:
    doc = _doc(slug)
    (ops,) = doc["paths"].values()
    (op,) = [v for k, v in ops.items() if k in ("get", "post", "put", "delete")]
    return op


def _validate(slug: str, schema: dict, instance: Any) -> None:
    root = {**schema, "components": _doc(slug).get("components", {})}
    jsonschema.validate(instance, root)


def validate_request(slug: str, body: Any) -> None:
    content = _operation(slug).get("requestBody", {}).get("content", {})
    if not content:
        assert body is None, f"{slug} takes no request body, got {body!r}"
        return
    (media,) = content.values()
    _validate(slug, media["schema"], body)


def validate_response(slug: str, status: int, body: Any) -> None:
    responses = _operation(slug)["responses"]
    assert str(status) in responses, f"{slug}: status {status} not documented"
    content = responses[str(status)].get("content", {})
    if "application/json" in content and body is not None:
        _validate(slug, content["application/json"]["schema"], body)
```

```python
"""Jamf Pro API client: auth, retries, pagination and the endpoints git2jamf uses."""

from __future__ import annotations

import logging
import time
from collections.abc import Callable
from datetime import UTC, datetime
from typing import Any

import requests

log = logging.getLogger("git2jamf")

TIMEOUT = (10, 60)
ATTEMPTS = 3
PAGE_SIZE = 200
REFRESH_MARGIN = 60
READ_RETRY_STATUSES = {429, 502, 503, 504}
EA_PATH = "/api/v1/computer-extension-attributes"


class JamfError(Exception):
    def __init__(
        self, message: str, *, method: str = "", path: str = "", status: int = 0, body: str = ""
    ):
        detail = f"{method} {path} -> {status}: " if method else ""
        excerpt = f" ({body[:500]})" if body else ""
        super().__init__(f"{detail}{message}{excerpt}")
        self.method, self.path, self.status = method, path, status


class JamfClient:
    def __init__(
        self,
        url: str,
        *,
        client_id: str | None = None,
        client_secret: str | None = None,
        username: str | None = None,
        password: str | None = None,
        session: requests.Session | None = None,
        sleep: Callable[[float], None] = time.sleep,
        clock: Callable[[], float] = time.monotonic,
    ):
        self.url = url.rstrip("/")
        self._client = (client_id, client_secret) if client_id else None
        self._basic = (username, password) if username else None
        self._session = session or requests.Session()
        self._session.headers["Accept"] = "application/json"
        self._sleep = sleep
        self._clock = clock
        self._token: str | None = None
        self._expires_at = 0.0

    # -- auth --------------------------------------------------------------
    def login(self) -> None:
        if self._client:
            data = {
                "grant_type": "client_credentials",
                "client_id": self._client[0],
                "client_secret": self._client[1],
            }
            response = self._send("POST", "/api/v1/oauth/token", data=data, auth_header=False)
            if response.status_code == 404:
                response = self._send("POST", "/api/oauth/token", data=data, auth_header=False)
            body = self._check(response, "POST", "/api/v1/oauth/token", "OAuth login failed")
            self._token = body["access_token"]
            self._expires_at = self._clock() + int(body["expires_in"])
        elif self._basic:
            response = self._send(
                "POST", "/api/v1/auth/token", basic=self._basic, auth_header=False
            )
            body = self._check(response, "POST", "/api/v1/auth/token", "login failed")
            self._token = body["token"]
            expires = datetime.fromisoformat(body["expires"])
            self._expires_at = self._clock() + (expires - datetime.now(UTC)).total_seconds()
        else:
            raise JamfError("no credentials configured")
        log.info("Authenticated to %s", self.url)

    def close(self) -> None:
        if not self._token:
            return
        try:
            response = self._send("POST", "/api/v1/auth/invalidate-token")
            if response.status_code not in (200, 204):
                log.warning("Could not invalidate the token (HTTP %s)", response.status_code)
        except requests.RequestException as exc:
            log.warning("Could not invalidate the token: %s", exc)
        finally:
            self._token = None

    # -- transport ---------------------------------------------------------
    def _send(
        self,
        method: str,
        path: str,
        *,
        auth_header: bool = True,
        basic: tuple[str | None, str | None] | None = None,
        **kwargs: Any,
    ) -> requests.Response:
        headers = {"Authorization": f"Bearer {self._token}"} if auth_header else {}
        return self._session.request(
            method, self.url + path, headers=headers, auth=basic, timeout=TIMEOUT, **kwargs
        )

    def request(self, method: str, path: str, **kwargs: Any) -> Any:
        if self._token and self._clock() > self._expires_at - REFRESH_MARGIN:
            self.login()
        reauthenticated = False
        attempt = 0
        while True:
            attempt += 1
            try:
                response = self._send(method, path, **kwargs)
            except (requests.ConnectionError, requests.Timeout) as exc:
                if method == "GET" and attempt < ATTEMPTS:
                    self._sleep(2**attempt)
                    continue
                raise JamfError(f"request failed: {exc}", method=method, path=path) from exc
            status = response.status_code
            if status == 401 and not reauthenticated:
                reauthenticated = True
                self.login()
                continue
            retryable = status == 429 or (method == "GET" and status in READ_RETRY_STATUSES)
            if retryable and attempt < ATTEMPTS:
                self._sleep(_retry_after(response, attempt))
                continue
            return self._check(response, method, path, "request failed")

    def _check(self, response: requests.Response, method: str, path: str, message: str) -> Any:
        if response.status_code >= 400:
            raise JamfError(
                message, method=method, path=path, status=response.status_code, body=response.text
            )
        if not response.content:
            return None
        return response.json()

    def _paginate(self, path: str, sort: str) -> list[dict]:
        results: list[dict] = []
        page = 0
        while True:
            body = self.request(
                "GET", path, params={"page": page, "page-size": PAGE_SIZE, "sort": sort}
            )
            results.extend(body["results"])
            page += 1
            if not body["results"] or len(results) >= body["totalCount"]:
                return results

    # -- scripts -----------------------------------------------------------
    def list_scripts(self) -> list[dict]:
        return self._paginate("/api/v1/scripts", "name:asc")

    def create_script(self, body: dict) -> str:
        return str(self.request("POST", "/api/v1/scripts", json=body)["id"])

    def update_script(self, script_id: str, body: dict) -> None:
        self.request("PUT", f"/api/v1/scripts/{script_id}", json=body)

    def delete_script(self, script_id: str) -> None:
        self.request("DELETE", f"/api/v1/scripts/{script_id}")

    # -- computer extension attributes -------------------------------------
    def list_extension_attributes(self) -> list[dict]:
        try:
            return self._paginate(EA_PATH, "name.asc")
        except JamfError as exc:
            if exc.status == 404:
                raise JamfError(
                    "this Jamf Pro version does not support extension attributes "
                    "through the Jamf Pro API",
                    method="GET",
                    path=EA_PATH,
                    status=404,
                ) from exc
            raise

    def get_extension_attribute(self, ea_id: str) -> dict:
        return self.request("GET", f"{EA_PATH}/{ea_id}")

    def create_extension_attribute(self, body: dict) -> str:
        return str(self.request("POST", EA_PATH, json=body)["id"])

    def update_extension_attribute(self, ea_id: str, body: dict) -> None:
        self.request("PUT", f"{EA_PATH}/{ea_id}", json=body)

    def delete_extension_attribute(self, ea_id: str) -> None:
        self.request("DELETE", f"{EA_PATH}/{ea_id}")

    def extension_attribute_dependencies(self, ea_id: str) -> list[dict]:
        return self.request("GET", f"{EA_PATH}/{ea_id}/data-dependency")["results"]

    # -- categories --------------------------------------------------------
    def list_categories(self) -> list[dict]:
        return self._paginate("/api/v1/categories", "name:asc")


def _retry_after(response: requests.Response, attempt: int) -> float:
    value = response.headers.get("Retry-After", "")
    return float(value) if value.isdigit() else float(2**attempt)
```

```python
"""Execute a plan through JamfClient."""

from __future__ import annotations

from dataclasses import dataclass
from enum import StrEnum

from git2jamf.jamf import JamfClient, JamfError
from git2jamf.models import Action, Kind, Verb

WRITES = (Verb.CREATE, Verb.UPDATE, Verb.ADOPT)


class Status(StrEnum):
    OK = "ok"  # written, or nothing to write
    PLANNED = "planned"  # dry run: would be written
    FAILED = "failed"
    SKIPPED = "skipped"  # delete skipped because an earlier action failed


@dataclass
class Outcome:
    action: Action
    status: Status
    detail: str = ""


def apply_plan(actions: list[Action], client: JamfClient, dry_run: bool) -> list[Outcome]:
    outcomes: list[Outcome] = []
    for action in actions:
        if action.verb in WRITES:
            outcomes.append(_write(action, client, dry_run))
        elif action.verb is not Verb.DELETE:
            outcomes.append(Outcome(action, Status.OK))
    failed = any(o.status is Status.FAILED for o in outcomes)
    for action in actions:
        if action.verb is not Verb.DELETE:
            continue
        if failed:
            outcomes.append(Outcome(action, Status.SKIPPED, "skipped: an earlier action failed"))
        else:
            outcomes.append(_delete(action, client, dry_run))
    return outcomes


def _write(action: Action, client: JamfClient, dry_run: bool) -> Outcome:
    detail = ", ".join(action.changes)
    if dry_run:
        return Outcome(action, Status.PLANNED, detail)
    try:
        if action.kind is Kind.SCRIPT:
            if action.verb is Verb.CREATE:
                client.create_script(action.payload)
            else:
                client.update_script(action.remote.id, action.payload)
        elif action.verb is Verb.CREATE:
            client.create_extension_attribute(action.payload)
        else:
            client.update_extension_attribute(action.remote.id, action.payload)
    except JamfError as exc:
        return Outcome(action, Status.FAILED, str(exc))
    return Outcome(action, Status.OK, detail)


def _delete(action: Action, client: JamfClient, dry_run: bool) -> Outcome:
    try:
        if action.kind is Kind.EXTENSION_ATTRIBUTE:
            dependents = client.extension_attribute_dependencies(action.remote.id)
            if dependents:
                names = ", ".join(
                    f"{d.get('type', 'object')} '{d.get('name')}'" for d in dependents
                )
                return Outcome(action, Status.FAILED, f"refusing to delete: used by {names}")
        if dry_run:
            return Outcome(action, Status.PLANNED)
        if action.kind is Kind.SCRIPT:
            client.delete_script(action.remote.id)
        else:
            client.delete_extension_attribute(action.remote.id)
    except JamfError as exc:
        return Outcome(action, Status.FAILED, str(exc))
    return Outcome(action, Status.OK)
```

```python
"""Log lines, GitHub annotations, step summary and action outputs."""

from __future__ import annotations

import json
from pathlib import Path

from git2jamf.apply import Outcome, Status
from git2jamf.models import Verb

_DONE = (Status.OK, Status.PLANNED)
_OUTPUT_VERBS = {
    "created": (Verb.CREATE,),
    "updated": (Verb.UPDATE, Verb.ADOPT),
    "deleted": (Verb.DELETE,),
    "unchanged": (Verb.UNCHANGED,),
}


def annotation(level: str, message: str) -> str:
    """GitHub workflow command; newlines must be URL-encoded."""
    encoded = message.replace("%", "%25").replace("\r", "%0D").replace("\n", "%0A")
    return f"::{level}::{encoded}"


def log_lines(outcomes: list[Outcome], dry_run: bool) -> list[str]:
    lines = []
    for o in outcomes:
        a = o.action
        prefix = "[dry run] " if dry_run else ""
        text = f"{prefix}{a.verb} {a.kind} '{a.name}'"
        if o.detail:
            text += f": {o.detail}"
        if o.status is Status.FAILED:
            lines.append(annotation("error", text))
        elif a.verb is Verb.ORPHANED or o.status is Status.SKIPPED:
            lines.append(annotation("warning", text))
        else:
            lines.append(text)
    return lines


def summary_markdown(outcomes: list[Outcome], dry_run: bool) -> str:
    title = "git2jamf plan (dry run)" if dry_run else "git2jamf sync"
    if not outcomes:
        return f"## {title}\n\nNothing to do.\n"
    order = {Status.FAILED: 0, Status.SKIPPED: 1}
    rows = sorted(outcomes, key=lambda o: order.get(o.status, 2))
    lines = [
        f"## {title}",
        "",
        "| Kind | Name | Action | Status | Detail |",
        "|---|---|---|---|---|",
    ]
    for o in rows:
        detail = o.detail.replace("|", "\\|").replace("\n", " ")
        lines.append(
            f"| {o.action.kind} | {o.action.name} | {o.action.verb} | {o.status} | {detail} |"
        )
    return "\n".join(lines) + "\n"


def outputs(outcomes: list[Outcome]) -> dict[str, str]:
    result = {}
    for key, verbs in _OUTPUT_VERBS.items():
        names = [o.action.name for o in outcomes if o.action.verb in verbs and o.status in _DONE]
        result[key] = json.dumps(names)
    changed = any(
        o.action.verb not in (Verb.UNCHANGED, Verb.ORPHANED) and o.status in _DONE for o in outcomes
    )
    result["changed"] = "true" if changed else "false"
    return result


def append(path: Path | None, text: str) -> None:
    if path is None:
        return
    with path.open("a", encoding="utf-8") as handle:
        handle.write(text)


def outputs_text(values: dict[str, str]) -> str:
    return "".join(f"{key}={value}\n" for key, value in values.items())
```

```python
"""Entry point: config -> scan -> login -> fetch -> plan -> apply -> report."""

from __future__ import annotations

import logging
import os
import sys
from collections.abc import Mapping, Sequence
from datetime import UTC, datetime

from git2jamf import config, marker, report
from git2jamf.apply import Status, apply_plan
from git2jamf.jamf import JamfClient, JamfError
from git2jamf.local import ScanError, scan
from git2jamf.models import Kind, LocalObject, RemoteObject
from git2jamf.plan import PlanError, PlanSettings, build_plan

log = logging.getLogger("git2jamf")

EXIT_OK, EXIT_FAILED, EXIT_CONFIG = 0, 1, 2


def main(argv: Sequence[str] | None = None, env: Mapping[str, str] | None = None) -> int:
    env = os.environ if env is None else env
    try:
        settings = config.load(argv, env)
    except config.ConfigError as exc:
        for problem in exc.problems:
            print(report.annotation("error", problem))
        return EXIT_CONFIG

    try:
        scanned = scan(
            settings.script_dir, settings.ea_dir, settings.script_extensions, settings.prefix
        )
    except ScanError as exc:
        for problem in exc.problems:
            print(report.annotation("error", problem))
        return EXIT_CONFIG
    for warning in scanned.warnings:
        print(report.annotation("warning", warning))

    kinds = frozenset(
        kind
        for kind, directory in (
            (Kind.SCRIPT, settings.script_dir),
            (Kind.EXTENSION_ATTRIBUTE, settings.ea_dir),
        )
        if directory
    )
    client = JamfClient(
        settings.jamf_url,
        client_id=settings.client_id,
        client_secret=settings.client_secret,
        username=settings.username,
        password=settings.password,
    )
    try:
        client.login()
        remote = fetch_remote(client, kinds, scanned.objects, settings.owner)
        categories = {}
        if any("category" in o.sidecar and o.sidecar["category"] for o in scanned.objects):
            categories = {
                c["name"].lower(): (str(c["id"]), c["name"]) for c in client.list_categories()
            }
        plan_settings = PlanSettings(
            owner=settings.owner,
            prefix=settings.prefix,
            delete=settings.delete,
            kinds=kinds,
            today=datetime.now(UTC).date().isoformat(),
            commit=settings.commit,
        )
        actions = build_plan(scanned.objects, remote, plan_settings, categories)
        outcomes = apply_plan(actions, client, settings.dry_run)
    except PlanError as exc:
        for problem in exc.problems:
            print(report.annotation("error", problem))
        return EXIT_FAILED
    except JamfError as exc:
        print(report.annotation("error", str(exc)))
        return EXIT_FAILED
    finally:
        client.close()

    for line in report.log_lines(outcomes, settings.dry_run):
        print(line)
    report.append(settings.summary_path, report.summary_markdown(outcomes, settings.dry_run))
    report.append(settings.output_path, report.outputs_text(report.outputs(outcomes)))
    failed = sum(o.status is Status.FAILED for o in outcomes)
    if failed:
        print(report.annotation("error", f"{failed} action(s) failed"))
        return EXIT_FAILED
    return EXIT_OK


def fetch_remote(
    client: JamfClient, kinds: frozenset[Kind], local: list[LocalObject], owner: str
) -> list[RemoteObject]:
    remote: list[RemoteObject] = []
    if Kind.SCRIPT in kinds:
        remote += [RemoteObject(Kind.SCRIPT, raw) for raw in client.list_scripts()]
    if Kind.EXTENSION_ATTRIBUTE in kinds:
        wanted = {o.name.lower() for o in local if o.kind is Kind.EXTENSION_ATTRIBUTE}
        for summary in client.list_extension_attributes():
            owned, _ = marker.parse(summary.get("description"))
            if summary["name"].lower() in wanted or owned.owner == owner:
                full = client.get_extension_attribute(str(summary["id"]))
                remote.append(RemoteObject(Kind.EXTENSION_ATTRIBUTE, full))
    return remote


def main_entry() -> None:
    logging.basicConfig(level=logging.INFO, format="%(message)s", stream=sys.stdout)
    sys.exit(main(sys.argv[1:]))
```

````markdown
# git2jamf [![License: MIT](https://img.shields.io/badge/License-MIT-yellow.svg)](https://opensource.org/licenses/MIT)

A GitHub Action that keeps Jamf Pro **scripts** and **computer extension attribute scripts** in sync with a Git repository. Git is the source of truth: files are created or updated in Jamf on every run, and (optionally) objects the action manages are deleted when their file is removed.

- **Safe deletes.** The action marks every object it manages and only ever deletes its own objects, never ones created by hand or by another repository.
- **Dry run.** See exactly what would change, in the job summary, before anything is written.
- **Settings in Git.** Category, priority, parameter labels and extension attribute options live in an optional YAML file next to each script.
- **Fails loudly.** Any error fails the workflow step.

## Quick start

1. In Jamf Pro, create an **API role** with the privileges listed under [Jamf privileges](#jamf-privileges) and an **API client** that uses it. Store the client ID and secret as repository secrets.
2. Add `.github/workflows/git2jamf.yml`:

```yaml
name: git2jamf
on:
  push:
    branches: [main]
  pull_request:

concurrency: git2jamf

jobs:
  sync:
    runs-on: ubuntu-latest
    steps:
      - uses: actions/checkout@v7
      - uses: jgarcesres/git2jamf@v2
        with:
          jamf_url: ${{ secrets.JAMF_URL }}
          jamf_client_id: ${{ secrets.JAMF_CLIENT_ID }}
          jamf_client_secret: ${{ secrets.JAMF_CLIENT_SECRET }}
          script_dir: scripts
          ea_dir: extension-attributes
          # Pull requests only show the plan; pushes to main apply it.
          dry_run: ${{ github.event_name == 'pull_request' }}
```

Try it against a test instance first, or start with `dry_run: true`.

## How it works

Each file becomes a Jamf object named after the file without its extension: `scripts/cleanup.sh` becomes the script `cleanup`, and `extension-attributes/battery_cycles.zsh` becomes the computer extension attribute `battery_cycles`. Names are compared case-insensitively. Files in folders whose name starts with a dot (such as `.github`) are ignored.

Every object the action writes gets a marker at the top of its **notes** (scripts) or **description** (extension attributes):

```
git2jamf: owner=acme/mac-scripts prefix=
git2jamf: created 2026-10-04
git2jamf: updated 2026-10-12 (commit 3f2a9c1)
Anything you write below the marker is kept.
```

| Situation | What happens |
|---|---|
| File exists, nothing in Jamf with that name | **create** |
| File exists, Jamf object has this run's marker | **update** if the contents or sidecar settings differ, otherwise **unchanged** |
| File exists, Jamf object has no marker (for example, created by v1) | **adopt**: the marker is added and the contents are synced |
| File exists, Jamf object is marked by a different owner or prefix | error, nothing is written |
| File removed, Jamf object has this run's marker | **delete** with `delete: true`, otherwise reported as **orphaned** |
| Jamf object without this run's marker and no file | ignored |

Changes are applied first; deletes only run if every change succeeded. An extension attribute that a smart group or advanced search depends on is never deleted (deleting it would also delete its inventory data); the run fails and lists the dependents instead.

## Inputs

| Input | Default | Description |
|---|---|---|
| `jamf_url` | (required) | Jamf Pro URL, e.g. `https://acme.jamfcloud.com` |
| `jamf_client_id` / `jamf_client_secret` | | API client credentials (recommended) |
| `jamf_username` / `jamf_password` | | User credentials, instead of an API client |
| `script_dir` | | Directory of scripts, relative to the repository root |
| `ea_dir` | | Directory of computer extension attribute scripts; excluded from `script_dir` |
| `script_extensions` | `sh zsh py` | Space-separated extensions to sync |
| `prefix` | | String added to every name as `<prefix>_<name>` |
| `delete` | `false` | Delete owned objects whose file was removed |
| `dry_run` | `false` | Report the plan, change nothing |
| `owner` | `${{ github.repository }}` | Ownership scope written into the marker |

Set exactly one credential pair, and at least one of `script_dir` and `ea_dir`.

## Outputs

| Output | Description |
|---|---|
| `created`, `updated`, `deleted`, `unchanged` | JSON arrays of names (`updated` includes adopted objects). In a dry run they describe the plan. |
| `changed` | `true` if anything was (or would be) written |

The job summary shows a table of every object and what happened to it.

## Sidecar settings

Add a `.yml` file with the same name next to a script to manage its settings. Every key is optional. Keys you leave out are not touched in Jamf (new objects get the defaults shown).

Scripts (`scripts/cleanup.yml` next to `scripts/cleanup.sh`):

```yaml
category: Maintenance      # must already exist in Jamf; null for no category (default)
priority: AFTER            # BEFORE, AFTER (default) or AT_REBOOT
info: Removes old caches
notes: Owned by the desktop team   # kept below the git2jamf marker
parameters:
  4: Days to keep
  5: Dry run (yes/no)
os_requirements: "14.x"
```

Extension attributes (`extension-attributes/battery_cycles.yml`):

```yaml
description: Battery cycle count   # kept below the git2jamf marker
data_type: INTEGER                 # STRING (default), INTEGER or DATE
inventory_display: HARDWARE        # GENERAL, HARDWARE, OPERATING_SYSTEM, USER_AND_LOCATION,
                                   # PURCHASING or EXTENSION_ATTRIBUTES (default)
enabled: true
```

Unknown keys are an error, so a typo fails the run instead of being ignored.

## Testing branches on one instance

Give each branch its own prefix. Objects are named `<branch>_<name>`, and a branch run only ever deletes objects with its own prefix:

```yaml
      - uses: jgarcesres/git2jamf@v2
        with:
          jamf_url: ${{ secrets.JAMF_URL }}
          jamf_client_id: ${{ secrets.JAMF_CLIENT_ID }}
          jamf_client_secret: ${{ secrets.JAMF_CLIENT_SECRET }}
          script_dir: scripts
          prefix: ${{ github.head_ref || github.ref_name }}
          delete: true
```

## Jamf privileges

The API role needs:

- Scripts: Create, Read, Update, Delete
- Computer Extension Attributes: Create, Read, Update, Delete (only if you use `ea_dir`)
- Categories: Read (only if a sidecar sets `category`)

Leave out Delete if you never set `delete: true`.

## Migrating from v1

v2 is a breaking release. v1 stays available at `@v1.4`.

| v1 | v2 |
|---|---|
| `jamf_username` / `jamf_password` with `jamf_auth_type: auth` | `jamf_username` / `jamf_password` (remove `jamf_auth_type`) |
| `jamf_username` / `jamf_password` with `jamf_auth_type: oauth` | `jamf_client_id` / `jamf_client_secret` |
| `script_dir` defaulted to the whole repository | `script_dir` or `ea_dir` is required |
| `ea_script_dir` (did nothing) | `ea_dir` |
| `prefix: true` (used the last segment of the branch name) | `prefix: ${{ github.head_ref \|\| github.ref_name }}` |
| `delete: true` deleted every script without a file | `delete: true` only deletes objects marked with this repository's owner and prefix |
| `script_extensions: 'sh py'` | default is now `sh zsh py` |

On the first v2 run, scripts v1 created are **adopted**: the marker is added and the existing notes are kept. Run with `dry_run: true` first to review the plan. Scripts that v1 created and whose files you have since removed have no marker, so v2 will not delete them; remove them in Jamf by hand if you want them gone.
````

- [ ] **Step 3: Add the notice to `action.py`**

Add `from datetime import datetime, timezone` after `import sys`, and replace the line `#run this thing` and the `if __name__ == "__main__":` line below it with:

```python
#v2 migration notice. main will become v2 (breaking changes); pin @v1.4 to stay on v1.
#During the brownout windows below (UTC) this action fails on purpose, before
#contacting Jamf, so workflows that track @main notice before the switch.
MIGRATION_URL = "https://github.com/jgarcesres/git2jamf/issues/26"
BROWNOUT_WINDOWS = [
    ("2026-11-17T15:00:00+00:00", "2026-11-17T19:00:00+00:00"),
    ("2026-11-24T15:00:00+00:00", "2026-11-24T23:00:00+00:00"),
    ("2026-12-01T15:00:00+00:00", "2026-12-02T15:00:00+00:00"),
]


def migration_notice(now=None):
    now = now or datetime.now(timezone.utc)
    message = ("git2jamf: main will switch to v2, which has breaking changes. "
               f"Pin jgarcesres/git2jamf@v1.4 to stay on v1, or move to @v2. See {MIGRATION_URL}")
    for start, end in BROWNOUT_WINDOWS:
        if datetime.fromisoformat(start) <= now < datetime.fromisoformat(end):
            print(f"::error::Planned brownout until {end}. {message}")
            return False
    print(f"::warning::{message}")
    return True


#run this thing
if __name__ == "__main__":
    if not migration_notice():
        sys.exit(1)
```

The check runs before any Jamf request. `datetime.fromisoformat` with `+00:00` offsets works on the Python 3.7 image v1 uses.
